# 覆盖度地图（骨架）

**这不是课程大纲。** 这是"这个主题里有哪些区域"的清单。

两者差别：
- 大纲有顺序、有深浅 → 那是路径，属于 `RUNTIME/trajectory/`，不属于种子层
- 地图只有区域和边界 → 用来判断"哪里是空的"，分叉时扫 `gap` 用

## 填写规则（BIRTH 阶段执行）

1. 只写区域名 + 一句边界描述。**不排序，不标难易，不写依赖**
2. 至少 3 个区域才算填完（断言 A4）
3. 区域名要能被"学完了/没学"二值判断
4. 拿不准的区域也写，标 `[uncertain]`——不知道有没有这块，本身就是信息

## 区域表

| 区域 | 边界（一句话） | 状态 | 备注 |
|---|---|---|---|
| （BIRTH 阶段填写） | | `empty` | |

状态取值：`empty`（没碰过） / `partial`（讲过部分） / `covered`（讲过且验收过）

## 更新时机

每轮 fork 后回填：
- 被排除但以后可能学的候选 → 回填对应区域，状态保持 `empty`，备注写候选 id
- 本轮兑现覆盖的区域 → 改 `partial` / `covered`

## 禁止

- 禁止在这里写学习顺序（"先 A 后 B"）
- 禁止把 deliver 的内容摘要抄进来（那是路径层，抄进来就污染了种子）
