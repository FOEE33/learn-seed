# baseline/ — 主题基线

**验证过的知识基线。** 不是知识库，不是教材。

## 放什么

- `coverage-map.md`：区域地图（骨架，所有主题共用结构）
- `<region-slug>.md`：某个区域里**已验证（D0）**的最小事实集，供兑现时引用出处

## 不放什么

- 学习顺序（那是路径）
- 未验证的内容（D1 只能留在本轮 deliver 里，进不了这里）
- 现成的教材章节、外部资料抄本（那是引用，不是基线）

## 一份基线条目的形状

```markdown
## <事实名>
- claim: 一句话
- source: 出处（链接 / 文档版本）
- verified_at: ISO8601
- used_in: cycles/0001, cycles/0004
```

## 原则

基线越小越好。基线的价值在于**可信**，不在于全。缺的部分靠兑现时搜（`RULES/search-scope.md` L3）补，补完验过再进这里。
